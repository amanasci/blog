Recently I have been working on a project that involves lot of effective dimensions calculations. So I though of writing a simple post about it. I will try to keep this post simple and we can discuss more complex tpoics in future posts.

But before that we need to understand the concept of dimensions. What I understand by the term "dimension" is the number of independent variables or features in a dataset, or in other words it's the number of features required to describe the state of anything. For example, a point in 3D space can be described by three coordinates (x, y, z), so it has three dimensions. However, if we have a dataset with 100 features, it doesn't necessarily mean that all 100 features are needed to capture the underlying structure of the data. Are all 100 features contributing equally to explplaining the state of the data? Probably not. Some features may be redundant, while others may be irrelevant. This is where the concept of effective dimensions comes into play.

Effective dimensions refer to the number of dimensions that are actually needed to capture the underlying structure of the data. It is a measure of the intrinsic dimensionality of the dataset, which can be much lower than the actual number of features. 

Now let's understand this using an example. Imagine we have a dataset of images of handwritten digits (0-9). Each image is represented as a 28x28 pixel grid, which means each image has 784 features (28*28). However, not all of these features are necessary to distinguish between the digits. In fact, many of the pixels may be blank or contain noise. The effective dimensions of this dataset may be much lower than 784, as only a subset of the pixels may be needed to capture the essential characteristics of the digits.

This is still complicated though. Let's start with some points in 3D space. Here is a set of points in 3D space:

```
(1, 2, 3)
(2, 4, 6)
(3, 6, 9)
(4, 8, 12)
```

At first glance, it seems like we have 3 dimensions (x, y, z). However, if we look closely, we can see that the points lie on a straight line. In fact, the z-coordinate is always three times the x-coordinate and the y-coordinate is always twice the x-coordinate. This means that the points can be described using only one dimension (the x-coordinate), as the y and z coordinates can be derived from it. Therefore, the effective dimensions of this dataset is 1, even though we have 3 actual dimensions.

How to see this mathematically? Let's use PCA (Principal Component Analysis) to find the effective dimensions. PCA is a technique that transforms the data into a new coordinate system such that the greatest variance by any projection of the data comes to lie on the first coordinate (called the first principal component), the second greatest variance on the second coordinate, and so on.

To perform PCA, we first need to center the data by subtracting the mean from each feature. Then we compute the covariance matrix of the centered data and find its eigenvalues and eigenvectors. The eigenvalues represent the amount of variance captured by each principal component, and the eigenvectors represent the directions of the principal components.

Let's do this for our data. The mean of the x, y, and z coordinates are:

```
mean_x = (1 + 2 + 3 + 4) / 4 = 2.5
mean_y = (2 + 4 + 6 + 8) / 4 = 5
mean_z = (3 + 6 + 9 + 12) / 4 = 7.5
```

Next, we center the data by subtracting the mean from each coordinate:

```
(1 - 2.5, 2 - 5, 3 - 7.5) = (-1.5, -3, -4.5)
(2 - 2.5, 4 - 5, 6 - 7.5) = (-0.5, -1, -1.5)
(3 - 2.5, 6 - 5, 9 - 7.5) = (0.5, 1, 1.5)
(4 - 2.5, 8 - 5, 12 - 7.5) = (1.5, 3, 4.5)
```

Now we compute the covariance matrix of the centered data. The covariance matrix is given by:

```
Cov = (1/n) * (X^T * X)
```

Where X is the matrix of centered data and n is the number of samples. After computing the covariance matrix, we find its eigenvalues and eigenvectors. The eigenvalues will indicate how much variance is captured by each principal component. In this case, we will find that one eigenvalue is significantly larger than the others, indicating that most of the variance is captured by the first principal component. This means that the effective dimensions of the dataset is 1, as the data can be effectively represented along a single dimension (the x-coordinate).

Here is a simple python code to perform PCA on the dataset:

```python
import numpy as np
# Original data
data = np.array([[1, 2, 3],
                 [2, 4, 6],
                 [3, 6, 9],
                 [4, 8, 12]])
# Center the data
mean = np.mean(data, axis=0)
centered_data = data - mean
# Compute covariance matrix
cov_matrix = np.cov(centered_data, rowvar=False)
# Compute eigenvalues and eigenvectors
eigenvalues, eigenvectors = np.linalg.eig(cov_matrix)
# Sort eigenvalues and eigenvectors
sorted_indices = np.argsort(eigenvalues)[::-1]
eigenvalues = eigenvalues[sorted_indices]
eigenvectors = eigenvectors[:, sorted_indices]
# Print eigenvalues
print("Eigenvalues:", eigenvalues)
```
 This gives us an output where one eigenvalue is significantly larger than the others, confirming that the effective dimensions of the dataset is 1.

In conclusion, effective dimensions refer to the number of dimensions that are actually needed to capture the underlying structure of the data. It is a measure of the intrinsic dimensionality of the dataset, which can be much lower than the actual number of features. PCA is a powerful technique that can help us identify the effective dimensions of a dataset by finding the principal components that capture the most variance in the data.

PCA is just one of many techniques for dimensionality reduction. Other techniques include t-SNE, UMAP, and autoencoders, each with its own advantages and disadvantages. The choice of technique depends on the specific characteristics of the dataset and the goals of the analysis. We can cover more techniques in future articles.

## Why study effective dimensions?

Understanding effective dimensions is crucial for several reasons:
1. **Dimensionality Reduction**: High-dimensional data can be difficult to visualize and analyze. By identifying the effective dimensions, we can reduce the dimensionality of the data while retaining most of the important information.
2. **Improved Performance**: Machine learning algorithms often perform better with fewer features, especially when the features are relevant. By focusing on the effective dimensions, we can improve the performance of our models.
3. **Noise Reduction**: Irrelevant features can introduce noise into the data,which can negatively impact the performance of machine learning models. By identifying and removing irrelevant features, we can reduce noise and improve the accuracy of our models.
4. **Interpretability**: Models that are based on a smaller number of effective dimensions are often easier to interpret and understand. This can be particularly important in fields like healthcare or finance, where understanding the factors that contribute to a decision is crucial.

In summary, effective dimensions are a fundamental concept in data analysis and machine learning that help us understand the intrinsic structure of our data. By identifying and focusing on the effective dimensions, we can improve the performance of our models, reduce noise, and enhance interpretability.
